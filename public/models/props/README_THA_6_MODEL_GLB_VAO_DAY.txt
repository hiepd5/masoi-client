THƯ MỤC NHẬN TRỰC TIẾP 6 ĐẠO CỤ 3D (.GLB) TỪ TRIPO PRO
=======================================================
Bạn chỉ cần đổi đúng 1 trong 6 tên file dưới đây và thả vào thư mục này,
sau đó vào Game bấm nút "🔧 Căn Đạo Cụ (.GLB)" -> "🔄 Quét lại .GLB" là lên hình ngay:

1. prop_chair.glb          -> Ghế gỗ sồi xếp vòng tròn (cao chuẩn 0.92m, mặt ghế 0.48m)
2. prop_campfire.glb       -> Bếp đá cổ ngữ trung tâm (cao chuẩn 0.42m, lửa động tự thắp)
3. prop_gallows.glb        -> Đài treo cổ hướng 12h Bắc (cao chuẩn 4.20m, dây đung đưa tự gắn)
4. house_cottage_a.glb     -> Nhà gỗ khung dầm mái ngói (cao chuẩn 5.80m)
5. house_cottage_b.glb     -> Nhà gỗ mái tranh ống khói đá (cao chuẩn 5.50m)
6. landmark_belltower.glb  -> Tháp chuông đá Gothic hướng Bắc (cao chuẩn 9.60m)

(Món nào chưa có file .glb, game tự động hiển thị bản Kiến Trúc 3D Dựng Sẵn, không bao giờ lỗi!)
